# Proyecto 02: Explorando la cultura con la web
## Integrantes:
- Fátima Torres
- César Balladares

## Actividad Seleccionada:
Participación ciudadana en los espacios de lectura y encuentro cultural dentro de la **Biblioteca de las Artes (Guayaquil)**.

## Descripción del Proyecto:
Sitio web interactivo enfocado en documentar, a través de storytelling visual y datos de campo (entrevistas a lectores, estudiantes, diseñadores y familias), el impacto de la Biblioteca de las Artes como núcleo de dinamización cultural, educativa y social en el centro de Guayaquil.
